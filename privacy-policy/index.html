Privacy policy

This policy describes the default behavior of AppScaffold. The site operator must keep this notice consistent with the services enabled on the deployed website.

Project generation and tool input

Project templates, configuration validation, code generation, and ZIP creation run in your browser. Generated source files and project configuration are not uploaded to a generation server. JSON samples, regex test text, and other tool inputs are processed locally and are not included in analytics events.

Local storage and retention

If “Remember configuration” is enabled, the generator stores your configuration in localStorage on your device so it can be restored after a refresh. This can include the project name, package name, description, and selected options. Do not put credentials or sensitive personal information in these fields. Theme preference is also stored locally.

Use “Clear saved configuration” in each generator to remove its saved configuration and pause saving. Browser site-data controls can remove all local data, including the theme preference. Generated archives remain in memory for the active page session and in your download folder if you save them. The website does not retain a server-side copy.

Hosting and technical requests

Your browser requests public website files from the hosting provider. The provider may process IP addresses, request times, browser information, and security logs according to its own policy. Browser-local generation does not eliminate ordinary website hosting requests. The operator should identify its hosting provider and retention practices before public launch.

Optional analytics

Analytics is disabled by default. If Google Analytics is configured and the consent integration permits it, the site can record non-sensitive events such as opening a generator, completing generation, downloading a ZIP, or using a named tool. These events do not include project names, package names, descriptions, generated source, or pasted JSON. Google may process technical information associated with analytics requests.

Cookies and advertising

Advertising is disabled by default. If Google AdSense is enabled after approval and consent permits advertising, Google and its partners may use cookies or similar technologies to deliver and measure ads. Personalized advertising can involve information about visits to this and other websites. See Google’s advertising technology policy and Google My Ad Center for information and available choices.

Consent and your choices

Non-essential scripts remain disabled until the configured consent adapter receives permission. The operator must connect an appropriate Consent Management Platform and expose its preference controls before enabling services that require consent. This application’s adapter does not independently determine regional legal requirements or certify compliance. Consent withdrawal should be handled through the deployed CMP, including any required cookie cleanup and page reload.

Third-party links

Documentation and package links take you to independent websites with their own privacy practices. The generator does not send your configuration as part of those links.

Questions and updates

Contact vivekpdev@gmail.com for privacy questions. This policy should be reviewed whenever hosting, analytics, advertising, or data handling changes.
