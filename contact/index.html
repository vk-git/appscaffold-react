Reporting a generator issue

Include the platform, architecture, selected libraries, SDK version, and a small description of what happened. If a generated project fails to build, a minimal error message is more useful than a complete source archive. Remove tokens, private endpoints, and personal information before sharing examples.

Before you report

Check the generated README for local platform-runner setup, Gradle wrapper creation, and code-generation commands. Review the architecture guides for the intended structure, and the privacy policy for data-handling details.
